# Спецификация: Матрица компетенций Frontend-инженера

## 1. Общие сведения
Интерактивный инструмент самооценки, целеполагания и подготовки к грейдированию frontend-разработчиков.

---

## 2. Грейдовая модель
Матрица включает 10 последовательных грейдов:
`E1.1`, `E1.2`, `E2.1`, `E2.2`, `E3.1`, `E3.2`, `E4.1`, `E4.2`, `E5.1`, `E5.2`.

Критерии сертификации грейда $G$:
1. **Mandatory (Обязательные):** 100% выполнение ($M_{completed} = M_{total}$).
2. **Desirable (Желательные):** $\ge 70\%$ выполнение ($D_{completed} \cdot 10 \ge D_{total} \cdot 7$).
3. **Vacuous Truth:** Если в грейде отсутствуют обязательные или желательные навыки ($total = 0$), покрытие считается $100\%$ ($1.0$).
4. **Непрерывность зачёта:** Текущий подтверждённый грейд ($G_{current}$) — наивысший грейд в непрерывной цепочке сертификации, начиная с $E1.1$.

---

## 3. Модель данных пользователя (`UserProgress`)

```typescript
export interface SkillProgressRecord {
  completed: boolean;
  completedAt?: string; // ISO string
  notes?: string;       // Заметки сохраняются независимо от факта сдачи
}

export interface UserProgress {
  version: string;      // "2.0.0"
  updatedAt: string;    // ISO string
  manualTargetGrade?: Grade | null;
  completedSkills: Record<string, SkillProgressRecord>;
}
```

---

## 4. GAP-анализ и выбор цели
- Эффективная цель ($G_{target}$): ручной выбор пользователя (если выбран грейд выше текущего), либо следующий по порядку авто-грейд ($G_{auto}$).
- Навыки со статусом `mandatory` во всех грейдах до $G_{target}$ включительно, которые не закрыты пользователем, помечаются как `gapSkills`.
