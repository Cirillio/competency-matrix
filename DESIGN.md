# Дизайн-система: Матрица компетенций

Строгий редакторский минимализм (Dieter Rams / Linear / Radix UI).  
Интерфейс строится на ступенях светлоты поверхностей и типографике, а не на обводках и градиентах.

---

## 1. Цветовые токены и ступени светлоты

| Токен | Значение | Назначение |
| :--- | :--- | :--- |
| `--surface-0` | `#090b0e` | Базовый холст приложения |
| `--surface-1` | `#11141a` | Основные блоки: карточка грейд-хиро, шапка, контейнеры |
| `--surface-2` | `#191d26` | Вложенные панели, плашки строк навыков, тиры лестницы |
| `--surface-3` | `#222834` | Активные элементы, поля ввода, выпадающие списки |
| `--text-primary` | `#f0f3f6` | Заголовки, основные названия навыков, текущий грейд |
| `--text-secondary` | `#97a1b0` | Описания, вторичный текст, топики |
| `--text-tertiary` | `#5e6878` | Метаданные, подписи, неактивные счётчики |
| `--accent` | `#3b82f6` | Единственный главный акцент: целевой грейд, фокус, чекбоксы |
| `--critical` | `#ef4444` | Сигнальный маркер: счётчик и точка GAP-блокеров |
| `--success` | `#10b981` | Маркер сданных грейдов в дорожной карте |

## 2. Правила композиции и разделения

1. **Никаких border-обводок для сетки:** Элементы и секции отделяются зазорами (16–24px) и разницей в светлоте (`--surface-0` $\to$ `--surface-1` $\to$ `--surface-2`).
2. **Максимум 2 акцента на экране:** Спокойный синий (`--accent`) для действий/целей и сдержанный красный (`--critical`) для блокеров.
3. **Типографическая иерархия:**
   - Display: Крупный номер грейда (40–48px, font-bold).
   - Headings: Названия компетенций и тиров (14–16px, font-semibold).
   - Body: Названия навыков и описания (13–14px).
   - Micro: Метаданные, топики, грейды (11–12px, font-mono).
