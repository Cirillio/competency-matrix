# Чеклист E2E-сценариев тестирования

Формат: `[Фича] Сценарий → Ожидаемо`

## 1. Аутентификация и сессия
- [Экран входа] Неавторизованный пользователь открывает приложение → Отображается экран входа с формой email/пароль.
- [Успешный вход] Ввод валидных учетных данных владельца → Успешный вход, переход в приложение, загрузка прогресса из Supabase.
- [Выход из системы] Клик по кнопке «Выход» в шапке → Сессия закрывается, локальный кэш очищается, удалённый прогресс остаётся нетронутым в Supabase.

## 2. Трекинг навыков и выбор цели
- [Отметка навыка] Клик по чекбоксу в строке навыка → Навык отмечается выполненным, пересчитывается прогресс, данные синхронизируются.
- [Сохранение заметки] Ввод текста в поле заметки и потеря фокуса (blur) → Заметка сохраняется в стейте и локальном хранилище.
- [Снятие отметки без потери заметки] Снятие галочки с навыка, имеющего заметку → Галочка снимается, но введённый текст заметки остаётся сохранённым.
- [Ручной выбор цели] Клик по ступени выше текущей на лестнице грейдов → Целевой грейд фиксируется, список GAP-блокеров расширяется на все промежуточные обязательные навыки.
- [Сброс цели] Клик по кнопке «Сбросить цель» → Целевой грейд возвращается к автоматическому расчету следующего уровня.

## 3. Импорт и экспорт
- [Экспорт] Нажатие кнопки экспорта в шапке → Скачивается валидный файл `matrix-progress.json`.
- [Импорт с orphan-ключами] Загрузка файла со старыми/удалёнными идентификаторами навыков → Валидные навыки восстанавливаются, устаревшие ключи безопасно отфильтровываются.
