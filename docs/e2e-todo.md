# Чеклист E2E-сценариев тестирования

Формат: `[Фича] Сценарий → Ожидаемо`

## 1. Аутентификация и сессия
- [Экран входа] Неавторизованный пользователь открывает приложение → Отображается экран входа с формой email/пароль.
- [Успешный вход] Ввод валидных учетных данных владельца → Успешный вход, переход в приложение, загрузка прогресса из Supabase.
- [Выход из системы] Клик по кнопке «Выход» в шапке → Сессия закрывается, локальный кэш очищается, удалённый прогресс остаётся нетронутым в Supabase.

## 2. Трекинг навыков и выбор цели
- [Отметка навыка] Клик по чекбоксу в строке навыка → Навык отмечается выполненным, пересчитывается прогресс, данные синхронизируются.
- [Сохранение заметки] Ввод текста в поле заметки и потеря фокуса (blur) → Заметка сохраняется в стейте и локальном хранилище.
- [Снятие отметки без потери заметки] Снятие галочки с навыка, имеющего заметку → Галочка снимается, но введённый текст заметки остаётся сохранённым.
- [Ручной выбор цели] Клик по ступени выше текущей на лестнице грейдов → Целевой грейд фиксируется, список GAP-блокеров расширяется на все промежуточные обязательные навыки.
- [Сброс цели] Клик по кнопке «Сбросить цель» → Целевой грейд возвращается к автоматическому расчету следующего уровня.

## 3. Импорт и экспорт
- [Экспорт] Нажатие кнопки экспорта в шапке → Скачивается валидный файл `matrix-progress.json`.
- [Импорт с orphan-ключами] Загрузка файла со старыми/удалёнными идентификаторами навыков → Валидные навыки восстанавливаются, устаревшие ключи безопасно отфильтровываются.
- [Грейды] Клик по текущему уровню в сводке → открывается диалог «Грейды» с 5 тир-группами.
- [Грейды] Клик по ступени выше текущей → цель меняется, счётчик блокеров пересчитывается, появляется «Вернуть авто-цель».
- [Блокеры] Клик по счётчику блокеров → поповер со списком тем и кнопкой «Показать в матрице» (включает фильтры).
- [Фильтры/мобильный] Кнопка «Фильтры» (<1024px) → открывается bottom-sheet; бейдж показывает число активных фильтров.
- [Навык] Клик по названию навыка → диалог с описанием, темами и ссылками.
- [Заметки] Клик по иконке заметки → поповер с textarea; закрытие по Escape сохраняет черновик.
- [Матрица] Отметка чекбокса → запись в localStorage и пересчёт блокеров.
- [Шапка] Меню → «Сбросить прогресс» открывает AlertDialog; подтверждение показывает тост.
- [ИИ] Шапка → иконка «Контекст для ИИ» → диалог с полем профиля и предпросмотром промпта.
- [ИИ] Заполнение профиля → текст сразу попадает в промпт; закрытие диалога сохраняет его в прогресс.
- [ИИ] Пустой профиль → промпт требует у модели сначала спросить об опыте.
- [Роутинг] Открыть /tracker без входа → редирект на /login?redirect=/tracker.
- [Роутинг] Вход с ?redirect=/tracker → после успеха попадаем на /tracker.
- [Каталог] Открыть / без входа → публичный каталог компетенций, без чекбоксов.
- [Каталог] Клик по навыку в каталоге → диалог с описанием, темами, ссылками.
- [Каталог] Поиск + фильтры «Уровень» (накопительный) и «Раздел» сужают список.
- [Наборы] Меню → «Наборы компетенций» → диалог с импортом и списком наборов.
- [Наборы] Вставка битого JSON → сообщение «не похоже на JSON»; кнопка «Добавить» заблокирована.
- [Наборы] Набор с id, совпадающим со встроенным навыком → ошибка «уже есть в матрице».
- [Наборы] Валидный набор → сводка (навыки, компетенции, уровни) → «Добавить» → тост, набор в списке.
- [Наборы] Тумблер набора off → его навыки исчезают из матрицы и из расчёта уровня.
